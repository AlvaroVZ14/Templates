# Templates

Repositorio base del proyecto Templates, inicialmente llamado Gym.

## Estado inicial

El proyecto está en preparación. El código, las dependencias y los comandos de
instalación y ejecución se documentarán cuando se defina la aplicación.

## Obtener el proyecto

```sh
git clone https://github.com/AlvaroVZ14/Templates.git
cd Templates
```

## Flujo de trabajo

- Realizar un commit por etapa con un mensaje claro.
- Hacer push al terminar cada etapa.
- Trabajar en la rama personal `student/<username>` y proponer los cambios mediante un Pull Request.
- Nunca subir claves, tokens ni archivos `.env`.
- Revisar los archivos preparados con `git diff --cached` antes de cada commit.

## Archivos ignorados

`.gitignore` excluye `node_modules/`, `dist/`, archivos `.env` y sus variantes,
y archivos de claves locales (`*.pem` y `*.key`).
